# Visual Acuity Calculator

A web-based calculator that determines the minimum readable text size based on screen specifications and visual acuity.

## Features

- **Dual Unit Systems**: Switch between Imperial (inches/feet) and Metric (cm/meters)
- **Screen Specifications**: Input diagonal size and resolution
- **Visual Acuity**: Select from standard Snellen acuity levels (20/20, 20/200, etc.)
- **Viewing Distance**: Specify how far you sit from the screen
- **Visual Simulator**: See a proportional representation of how text would appear
- **Real-time Calculations**: Instant results for PPI, minimum text height, and recommended font size

## Usage

1. Select your preferred unit system (Imperial/Metric)
2. Enter screen diagonal size
3. Input screen resolution (width × height pixels)
4. Select your Snellen acuity level
5. Specify viewing distance
6. Click "Calculate Minimum Text Size"
7. View results and visual simulator

## Technical Details

- Pure HTML/CSS/JavaScript (no dependencies)
- Responsive design for mobile and desktop
- Accurate calculations based on visual acuity principles
- Proportional text scaling for simulator
